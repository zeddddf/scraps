# Perf

当前首版已经落地的性能策略：

- 历史数据使用 `SQLite WAL`
- 搜索使用 `FTS5`
- 历史列表使用 `LVS_OWNERDATA` 虚拟列表
- 列表按页异步加载，默认页大小 `128`
- 图片原始数据落盘，不直接塞进数据库
- 来源应用图标异步提取并缓存
- 选中图片后先显示文本占位，再异步解码预览
- 变形粘贴与复制路径使用共享抑制状态，避免无意义重复入库

当前仍需继续优化的点：

- 列表仍然基于原生 `ListView`，不是最终 D2D 自绘版本
- 预览缓存还是首版实现，尚未形成完整缩略图缓存层
- 后台线程目前是轻量分发，不是正式线程池
